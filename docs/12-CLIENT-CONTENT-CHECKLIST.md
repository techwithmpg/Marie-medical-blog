# 12 — Client Content Checklist

Development can proceed with placeholders, but launch requires approved real content.

## Identity/brand
- [ ] Final public/professional name
- [ ] Final tagline or approval of recommended tagline
- [ ] Confirmation whether a separate publication name is desired
- [ ] Optional logo/wordmark approval

## About/profile
- [ ] Short bio
- [ ] Long bio
- [ ] Education details approved for public display
- [ ] Relevant experience
- [ ] Achievements/certifications
- [ ] Medical interests
- [ ] Writing interests
- [ ] Professional goals
- [ ] Preferred public contact details
- [ ] LinkedIn/professional social links if any

## CV
- [ ] Current approved PDF CV

## Launch content
Recommended minimum:
- [ ] Article 1
- [ ] Article 2
- [ ] Article 3
- [ ] Optional Article 4
- [ ] Optional Article 5

Each launch article should have:
- [ ] final title
- [ ] reviewed body
- [ ] references
- [ ] category
- [ ] featured image rights/asset if used
- [ ] image alt text or enough context to write it
- [ ] excerpt

## Categories
Start with roughly 5–7 broad categories, approved by Marie. Avoid creating too many empty topics at launch.

## Contact
- [ ] Public contact email / form delivery target

## Domain
- [ ] Final domain name
- [ ] Registrar access / DNS coordination available for launch

## Privacy preference
- [ ] Confirm no profile image is required
- [ ] Confirm which education/location details Marie is comfortable displaying publicly
